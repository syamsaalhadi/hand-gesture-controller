# 🖐️ Neural Hand Recognition System

> **AI-Powered Real-Time Hand Gesture Detection with Modern Web3 Interface**

A sophisticated web application that uses Machine Learning to detect hand gestures in real-time and convert them into voice commands. Built with MediaPipe, modern JavaScript, and featuring a stunning blockchain-inspired UI.

## ✨ Features

- **🤖 Real-Time AI Detection** - Powered by Google's MediaPipe hand tracking model
- **🖐️ 5 Gesture Recognition** - Custom mappings: 1-5 fingers → Voice commands
- **🎨 Modern Web3 UI** - Glassmorphism design with neon aesthetics
- **📊 Performance Monitoring** - Live FPS, latency, and accuracy tracking
- **🔊 Indonesian Voice Synthesis** - Text-to-speech with natural pronunciation
- **📱 Responsive Design** - Works on desktop and mobile devices
- **⚡ Hardware Accelerated** - WebGL optimization for smooth performance

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **ML/CV:** MediaPipe Hands, TensorFlow.js
- **APIs:** WebRTC, Web Speech API, Canvas API
- **Design:** Glassmorphism, CSS Animations, Inter Font

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/syamsaalhadi/hand-gesture-controller
cd hand-gesture-controller

# Serve locally (Python)
python -m http.server 8000

# Or use Live Server in VS Code
# Open index.html with Live Server extension
```

Visit `http://localhost:8000` and allow camera permissions.

## 🎯 Gesture Commands

| Gesture | Command | Description |
|---------|---------|-------------|
| 1️⃣ | **NAMA** | One finger pointing |
| 2️⃣ | **SAYA** | Peace sign / Two fingers |
| 3️⃣ | **SYAMSA** | Three fingers extended |
| 4️⃣ | **AL** | Four fingers (no thumb) |
| 5️⃣ | **HADI** | Open palm (all fingers) |
